## Notes (non-blocking)
1. Pre-auth buffering: an unauthenticated caller with a current timestamp and any 64-hex v1 makes the
   service buffer up to 16 MiB before the HMAC check (server.mjs:145-160). Inherent to a body-bound MAC;
   private network only. Consider streaming the sha256 instead of buffering if T9 shows memory pressure.
2. Replay set is per-process (design accepts "in-memory"): a replay to a second replica, or to the same
   replica after a restart, inside 60 s is admitted. Record this against replica count >1 at T10/T20.
3. bars.sha256 layout (protocol.mjs:90-94) is not pinned by an independent recomputation: helpers.mjs
   builds the fixture hash with the same barsSha256, so a layout change stays green. T11's cross-language
   fixture must pin it (EVIDENCE open item already says T11 owns the fixture; make it explicit).

   text. Sound, documented in protocol.mjs:13-25; T11 must mirror.

   silently dropped rather than refused. Harmless (no pollution with primitives; runtimeBuildInputs
   re-validates), but Object.create(null) or a refusal would be cleaner.
