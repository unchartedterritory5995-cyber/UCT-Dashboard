# Pullback to the 21-day EMA — Blind Adjudication (Judge 1)

**Method note:** Each case was judged from two chart images — a structure view (last ~130 bars, with SMA50, SMA200, and a gold 21-EMA line) and a detail view (last ~35 bars, with the same gold 21-EMA line and volume) — plus the packet's neutral price/volume context (SMAs, %-of-52w-high/low, ADR%, volume averages) only. No pattern-detector source code, detector output, or any prior adjudication/trace file was read or consulted. Both images always end at the same evaluation date; no separate candidate marker was needed. The gold line is the 21-EMA, a neutral technical overlay.
