# Bull Flag Blind Adjudication — Judge 1

**Method note:** Each case was judged from two chart images — a structure view (last ~90 bars, with moving averages) and a detail view (last ~45 bars, with moving averages and volume) — plus the packet's neutral price/volume context (SMAs, %-of-52w-high/low, ADR%, volume averages) only. No pattern-detector source code, detector output, or any prior adjudication/trace file was read or consulted. Both images always end at the same evaluation date; no separate candidate marker was needed.
