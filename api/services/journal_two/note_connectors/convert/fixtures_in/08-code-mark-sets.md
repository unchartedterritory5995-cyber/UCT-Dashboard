Code mark exclusivity (D3 item 2). The editor's `code` mark excludes every
other mark: a code run inside a link keeps the LINK and drops the code mark,
and a code run inside bold or italic keeps only the code mark.

See [the `x` plan](https://example.com/plan) and [`deck`](https://example.com/deck).

Bold code **`risk`** and italic code *`size`* and ***`both`***.

A [**bold `y` link**](https://example.com/y) keeps link and bold.
