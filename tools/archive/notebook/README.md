# Archived notebook build-wave scripts

These are one-time walks, probes and mutation proofs written during the notebook build waves. They are kept for history only and are not maintained; nothing in CI, the tests or the runbooks runs them.
Several import helpers that stayed in `tools/` (for example `notebook_perf_harness`), so they may not run from this folder as they are.
To restore one, move it back: `git mv tools/archive/notebook/<name> tools/<name>`.
