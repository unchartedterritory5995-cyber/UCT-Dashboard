# UCT Terminal — accessibility and phone/tablet audit, 2026-10-06

Lane `terminal/fn4-a11y` (worktree `tf4-a11y`, from `origin/master` `0ae75faf3`).
Scope: `app/src/pages/terminal/**`, `app/src/components/terminal/**`, and the shell's
treatment of the panels it mounts. Mounted panels that live elsewhere (research tabs,
options analytics, screener, calendar…) were surveyed, not fixed — see §5.

Method: static source review plus computed contrast. jsdom does no layout, so nothing
here is a device or screen-reader result; it is necessary, not sufficient. Every fix
below has a rail that goes red if it regresses.

## 2. Contrast — how it was measured, and the fix

`app/src/pages/terminal/a11y/__tests__/terminalContrast.js` walks every stylesheet under
`pages/terminal` and `components/terminal`, takes each `color:` (and `fill:` on SVG text
classes), resolves tokens in **21 themes** — `dark` (`:root`), `oled`, `light`, and the 18
catalog themes built exactly as `applyAppTheme` builds them (oled or light base + the
theme's inline tokens) — and measures against `--bg`, `--bg-surface`, `--bg-elevated`
and `--bg-hover` (or the rule's own background), compositing opacity and alpha. One
formula: `styles/__tests__/contrastMath.js`. Bars: 4.5:1, or 3:1 for large text.

Before: 8,694 pairs, **322 under the bar**, all from three causes (F1, F2, F11).
After: **0**.

Worst pairs before the fix (`--loss` as text):

| theme | surface | ratio |
|---|---|---|
| Nord | `--bg-hover` | 3.18 |
| Midnight Navy | `--bg-hover` | 3.43 |
| Slate | `--bg-hover` | 3.51 |
| Nord | `--bg-elevated` | 3.65 |
| Gunmetal / Storm / Deep Forest / dark | `--bg-hover` | 3.65–3.68 |
| Sand (`--gain`) | `--bg-hover` | 4.19 |

**The fix lives in tokens, not terminal CSS.** `--loss` / `--gain` also colour chart
candles and dozens of non-terminal surfaces, so they were not moved. Terminal TEXT now
uses the existing text inks `--danger-ink` / `--success-ink` (introduced by the Notebook's
D-A4 ruling for exactly this purpose), and `--danger-ink` was lifted from `#e67070`
(`:root`) / `#e35e5e` (oled — which every dark catalog theme inherits) to **`#e87878`**,
same hue: **4.61:1 worst** (Nord hover). `--success-ink` already cleared every surface
(light `#1a703f`: 4.78:1 worst). The Earnings Research modal's theme island pins the new
value. Lifting `--danger-ink` only raises the Notebook's own contrast; its rail stays green.

## 5. Mounted panels outside the terminal (surveyed, not fixed)

The shell mounts ~50 existing pages/tabs as panels. A source survey of the research tabs,
options analytics, options screener, calendar, UCT20, Breadth, Flow Scoreboard, Catalysts
History, Portfolio Heat and Morning Wire found:

- **46 of 52 `<table>`s have no accessible name** (most: `ResearchComparePage.jsx` 4,
  `PeopleTab.jsx` 3, `StrategyScreensPanel.jsx` 3, `OptionsScreener.jsx` 3, `EstimatesTab`,
  `OwnershipTab`, `ChainModelPanels`, `MarketTidePanel`, `FlowScoreboard` 2 each). The
  panel's `<section aria-label="Panel N: …">` gives a screen reader the context, but each
  table still announces as an unnamed table.
- **`color: var(--loss)` is used as text in 212 declarations and `var(--gain)` in 157**
  outside the terminal and Journal 2.0 — the F1/F2 contrast failure applies to all of them
  on the same themes and surfaces.
- 1 of 10 inline `<svg>`s is neither named nor hidden.

1. **App-wide loss/gain text contrast.** Either (a) lift `--loss` itself in `:root`/oled
   (one token change, fixes all 212 uses, but also lightens chart candles and every red
   fill), or (b) sweep the 369 text declarations onto `--danger-ink` / `--success-ink`
   surface by surface (no visual change to charts; many owners). This lane did (b) for the
   terminal only. Recommendation: (b), lane by lane, with `terminalContrast`'s audit
   generalised as the rail.
2. **Mounted-panel table names** (§5): fix in each owning surface, or have the shell label
   unnamed tables inside a panel body at runtime. Recommendation: fix at source; a runtime
   patch would hide the gap from those surfaces' own tests.
3. **10px chart labels** (F12): raise the chart text floor to 11–12px with the themes lane.
4. A real screen-reader pass (NVDA + VoiceOver iOS) and a device pass at 390/820px —
   nothing here can stand in for either.
