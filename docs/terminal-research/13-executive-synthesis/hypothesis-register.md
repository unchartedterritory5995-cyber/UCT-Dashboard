# Hypothesis register — Terminal-Next

**Vocabulary.** TERMINAL-CURRENT = the `/calendar` surface, display-named "UCT Terminal" since 2026-09-01 (route, keys, `/api/calendar/*` unchanged). TERMINAL-NEXT = the product this program designs. UT is the parent brand; UCT Intelligence is the product.

**What this file is.** The single register of every hypothesis the program is proceeding on — the five seed hypotheses from the directive (H1–H5) plus every hypothesis the Wave 1 / 1b evidence raised (H6–H35). Each row names the artifacts behind its status, the evidence on both sides, the one test or owner fact that would settle it, and the decision it feeds. A hypothesis here is never a requirement; "supported" means the evidence on file favours it, not that it has been decided. Where a benchmark is cited, "product X does Y" is carried as an observation, never as an argument (charter Parts CCXLVIII–CCXLIX).

**Status legend.**

| Status | Meaning in this register |
|---|---|
| **supported** | The evidence on file favours the hypothesis and no artifact contradicts it; the remaining uncertainty is measurement, not direction. |
| **partially supported** | Evidence favours part of the sentence (usually one audience, one tier, or the structural half) and contradicts or leaves open the rest. |
| **unsupported** | The evidence on file contradicts the hypothesis as stated; it may still be true in a narrower form named in the row. |
| **unknown** | Nothing on file settles it in either direction; the row names the owner input or test that would. |

**Citation key.** `D-06 §1.7` = section 1.7 of the D-06 report; `F-04 T-75` = row T-75 of the licensing register; `F-06 Q22` = the executive-questions answer to Q22 (its own citations, e.g. `TD-17`, are carried one step removed); `B-POD-BBG §A` = section A of the Bloomberg pod dossier; `B-BBG-08 §2` = the "why they stay" leaf; `B-UW M-3` = Unusual Whales dossier, best-ideas item 3; `B-TV N6` = TradingView dossier, bad-ideas item 6; `CP-05`, `R-13`, `OI-03`, `OQ-04`, `RG-06`, `DL-010`, `D-002` = rows in the control files of the same name. "CLAIM" and "CONFIRMED" follow the shared preamble; where a cited artifact itself marks a fact CLAIM, that label is carried, never upgraded.
