# Tech-debt register — terminal-relevant debt only (Part CXVIII)

**Vocabulary.** TERMINAL-CURRENT = the `/calendar` surface, display-named "UCT Terminal" since 2026-09-01. TERMINAL-NEXT = the product this program designs. Brand: UT parent, UCT Intelligence product.

**How to read this file.** One entry per debt item, classified per Part CXVIII: **Blocks Terminal** (a Terminal-Next build cannot start or ship a credible first slice without a decision on it), **Increases Risk** (a Terminal-Next build inherits or amplifies it), **Opportunistic** (cheap, adjacent, worth taking only if a hand is already in the file), **Unrelated — leave alone** (real debt, not this program's, and touching it would widen blast radius). Every entry carries evidence (`path:line`, CLAIM vs CONFIRMED), the leaf that found it, why it matters for Terminal-Next, and a confidence mark. Nothing here is a requirement; observations are inputs for the architecture roles (ARCH-01..08), the coexistence plan (H-07) and the backlog (gate 20). Cross-references: `system-map.md` (MAP §n, R-n), `capability-ledger.md` (row ids A1…P11). Two entries are pinned by id because the system map cites them: **TD-19** (flag ledger drift) and **TD-40** (Desk show privacy).

**Not in this register.** Provider-contract and licensing debt (F-03b, F-04); Terminal-Current *product* gaps that are design choices rather than defects (D-09 §11 lists them); proprietary-asset retention decisions that are product calls (D-13); the owner's open commercial questions (OQ-03, OQ-04, OI-12).
