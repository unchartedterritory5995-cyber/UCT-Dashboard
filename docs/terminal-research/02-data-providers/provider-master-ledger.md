**Vocabulary.** TERMINAL-CURRENT = the `/calendar` surface, display-named "UCT Terminal" since 2026-09-01 (route, `calendar` door key, `/api/calendar/*`, filenames, CSS unchanged). TERMINAL-NEXT = the product this program designs. UT is the parent brand; UCT Intelligence is the product.

**What this file is and is not.** Per owner directive DL-022 (`/btw`), this restructures the already-accepted 48-row provider ledger (F-03b) into a full per-asset-class capability matrix per provider, applies the owner's **A–G usage-status taxonomy**, and separates **technical access** from **contractual right** at the per-capability level. **Two taxonomies in this file — do not conflate them.**
* **Usage class (A–G)** — the owner's new taxonomy (GOVERNING_PRINCIPLES §14A), about *whether and how a capability is used today*: **A** currently used · **B** configured but underutilized · **C** available through a current provider but not yet consumed · **D** duplicative/overlapping · **E** legacy/dormant · **F** licensing unknown · **G** missing from the stack entirely.
* **Licensing class** — F-04's taxonomy, about *legal risk*: **A** Allowed (public-domain/own-content only) · **LA** Likely Allowed (verify contract) · **R** Restricted (a public clause collides on its face) · **U** Unknown (clause unreachable or tier unresolved) · **X** Unsuitable (no purchasable remedy).
Both use the letter "A" for different things by coincidence. Every table below labels which column is which.

**Status ladder** (unchanged from F-03b, ascending): **KP** KEY-PRESENT → **CR** CODE-REFERENCED → **OC** OBSERVED-CALLED → **CA** CONTRACT-ACTIVE (no row reaches CA in this program).
