## 0. How the Agent is wired (what "A" means)

- **Registry.** 119 capabilities are registered (`grep "name: '<x>.<y>'" app/src/agent/capabilities/*.js`) through `registerCapability` (`app/src/agent/capabilities.js`). `availableCapabilities()` (capabilities.js:164-171) drops a capability when `c.surfaces` does not include `ctx.surface` (:168) or `available(ctx)` is false. `builtins.js:31-57` loads every module; `registerServerGatedBuiltins()` (:63-65) adds the market-data ones only after `/api/agent/config` answers.
- **Surface restriction — confirmed.** Every one of the 55 explicit `surfaces:` declarations is `['charts']` and every module-level `common` object is `surfaces: ['charts']` (board.js:597, chart.js:809, chartSetup.js:130/250, definitions.js:108, drawings.js:173, guide.js:123, indicatorAuthoring.js:827, workspace.js:202/259, marketDataQuote.js:237, marketDataBars.js:185). `useAgent({ host, gridMode, surface = 'charts' })` (useAgent.js:301) is the only caller and never passes another surface. The panel is mounted in exactly one place: `pages/charts/ChartsWorkspace.jsx:3759-3766` (`<AgentDock>` + `<AgentPanel host={agentHost}>` + `<AgentNavBridge>`), behind `agentAllowed = agentFlag && isAdmin` (:2960) where `agentFlag` is the per-browser `uct.feature.agent` localStorage switch (`agent/agentFlag.js:18`, DEFAULT_ON = false). `pages/charts/mobile/MobileChartsApp.jsx` has no mount (0 matches). The only other Agent entry is the Trade Exchange News "Ask" box (`agent/newsAsk.js` seam → `TradeExchangeNewsAsk.jsx`), which only sends headline chats and is itself admin + flag gated; it renders wherever that widget renders. Server side every `/api/agent/*` route is `require_admin_dark` (`api/routers/uct_agent.py:89-91`, :175-526).
- "surfaces" in a registry entry is therefore a string list matched against `ctx.surface`; the only value that exists anywhere is `'charts'`, and the only host that exists is the Charts workspace host (`agent/host.js:504 buildWorkspaceHost`, built at ChartsWorkspace.jsx:3116).
- So **"A = working" below means: the capability is registered, available on /charts, and goes through the feature's own writer — when the Agent is switched on for an admin browser.** The whole Agent is dark for members; that is one product switch, not counted per row.
- **Server feature flags** (per row where relevant): `UCT_AGENT_NEWS` (services/uct_agent/news.py:17, default OFF), `UCT_AGENT_DATA` + `UCT_AGENT_DATA_KINDS` fail-closed allow-list + `UCT_AGENT_SCAN` + `UCT_AGENT_ISOLATED` (services/uct_agent/marketdata/gateway.py:41-50), `UCT_AGENT_STREAM` (routers/uct_agent.py:182), `UCT_AGENT_NL1` (services/uct_agent/turn.py:95). `/api/agent/config` reports `stream, nl1, news, data, scan, data_kinds` (routers/uct_agent.py:189-197).
- **The rule.** `app/src/agent/README.md` "Rules that do not bend": no capability without a deterministic writer the manual UI also uses; no DOM/browser control; indicators go through Indicator Intelligence's seams; drawings through `drawingsStore` by symbol + id.

## 3. Actions with NO programmatic writer (DOM/UI only)

These are per-browser `localStorage` state or pure UI state with no server/prefs writer, so the Agent rule (no DOM control) blocks them until the product grows a writer:

- Watchlist column layout `uct.watchlist.cols` (registry.js:402 comment: "column layout lives in localStorage, NOT opts").
- Screener layout / grid layout / pinned / watchlist target (`uct.screener.*`, localStorage only).
- Breadth page collapsed columns (`breadth_collapsed_cols`, Breadth.jsx:723/735) and views cache (`uct.breadth.views.v2`).
- Model Book panel tab / width / show-all toggles (`modelbook_panel_*`), Desk section / video progress (`uct.desk.*`), Journal sidebar / open-positions view (`uct.j2.*`), AI-search mode (`uct.aisearch.mode`).
- Drawing-tool recents (`uct.draw.recentTools`), chart mobile recents.
- Chart pop-outs / floating windows are side-effect UI (window.open), reachable only via ChartsWorkspace handlers (row 17).
- Replay cutoff and the Compare panel are component state reached only through ChartsWorkspace handlers (rows 14, 5) — writers exist but Replay is not on the host yet.
