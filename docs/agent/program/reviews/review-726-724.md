### (3) One metered web call per turn — PARTIAL (blocking item B1)

- **B1 (blocking, correctness):** `web_for_turn` (rs1.py:461-475) keys the cache by `(user_id, turn_id)` only. A second research read in the same turn for a DIFFERENT symbol or query gets the FIRST read's web answer. Example: "why are NVDA and AMD down", where the planner emits two `research.ask` ops. AMD's "Interpretation" section would then show NVDA's commentary. The figure gate only checks numbers, so number-free sentences about the wrong company pass. The test `test_at_most_one_web_call_per_turn…` asserts this sharing across different topics. Fix: key the cache by `(user, turn, symbol, query)`. For a second distinct query in the same turn, make no call and add an unknown line ("the turn's web lookup was already used"); do not reuse.
- Non-blocking:

### (4) Figure gate — bypasses found (blocking item B2)
Probed `unconfirmed_figures` with synthetic sentences; allowed set built from {last 142.1, change −2.34, volume 31,000,000}:
- **B2 (blocking): month-prefix false "dates".** `_MONTH = (?:jan|feb|mar|…|dec)[a-z]*` (rs1.py:55), used in `_DATE_NUM_RE` (:57-59), matches ordinary words: "declined", "decreased", "margin", "market", "novel", "may". The following 1–2-digit number is then erased as a date. Results:
  - "Shares declined 18% after the report." → passes
  - "Gross margin 75% beat views." → passes
  - "The market 40% rally." → passes
  - "Decreased 9 points." → passes
  "Why is X down" is exactly the case where web prose says "declined N%". Fix: whole month names/abbreviations only, e.g. `\b(?:jan(?:uary)?|feb(?:ruary)?|mar(?:ch)?|apr(?:il)?|may|jun(?:e)?|jul(?:y)?|aug(?:ust)?|sep(?:t(?:ember)?)?|oct(?:ober)?|nov(?:ember)?|dec(?:ember)?)\b\.?`, plus tests for the cases above.
- Non-blocking (record as known limits in RS-1 §4.1):
  - Any integer 1900–2099 is treated as a year (`\b(?:19|20)\d\d\b`): "a 2050 price target" passes.
  - Sign is ignored (`lstrip("+-")` at :153 and `abs` at :140): "fell 2.34%" passes when the data said +2.34.
  - Units are ignored: "rose 31%" passes because volume 31,000,000 / 1e6 = 31. Every number ≥1e3 adds scaled values within ±0.05 (:142-144), and every numeric field in every input (limits, counts, ids) is admitted. The allowed set is wide.
  - Spelled-out or relative quantities pass: "doubled", "half", "two hundred", "½".
  - Numbers inside URLs and letter-glued tokens ("up10%") are over-strict, not a bypass.
  - News headlines in `sources[].title` are not figure-gated. They are attributed and dated, but the rule as written covers only facts/interpretation.
