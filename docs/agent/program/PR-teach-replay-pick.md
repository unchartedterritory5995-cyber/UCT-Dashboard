## What a member gets

Asked "how do I pick the cutoff on the chart" (or the same in other words), the Agent walks:

1. Tools ▾ (ring on the Tools button)
2. Replay Mode
3. **Pick on chart**: the real button in the Replay Mode panel. The panel closes and the chart arms ("Set replay cutoff").
4. The chart: click the bar to replay to. The step waits for Replay Mode to reopen with that date.
5. **Start replay** (it says Update while a replay is running).

## Known limits

- The browser runner proves the ring reaches each step's control and that the chart click reopens the panel; it does not assert the date value that lands in "Replay to", nor that Start replay then hides the right bars.
- On a multi-chart board the chart step rings the chart being talked about; the product arms only the active chart (`ChartWidget.jsx` replayArmPick is one workspace flag). If they differ, the member's click on another chart still picks the date.
- The picker arms on a mouse pointer only (`StockChart.jsx` replayPick handler ignores touch), so on a phone the step waits; Replay Mode's date box is the fallback.
- `CHARTS_TEACH_STATUS.md` is not regenerated here (that needs the full inventory run); C1-044 and C3-211 move to VERIFIED on the next full run.
- `guide/*` changed, so CI's notebook-bytes gate measures this PR (actions.js +~1.3 KB source; not measured locally).
