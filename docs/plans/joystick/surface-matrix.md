## ⚠️ What the Write path column does and does not claim

`—  (route only)` is structural: `navigate` and `home` change the route and nothing else.
`?` means **the join did not resolve — not "writes nothing."** An action is credited with an
endpoint only when its handler arm calls a symbol that the manifest's own `via` module defines as
performing that write, and most hub actions reach their endpoint through a **hook's return value**
(`toggle` from `useFlagged`, `createAlert` from `useWatchlistAlerts`). Following those out is
dataflow analysis, not a scan — `writePaths.test.js` says so itself in its coverage-boundary
header, and this tool inherits that boundary rather than papering over it. **For the authoritative
list of the seven endpoints the hub can write, read the manifest in `writePaths.test.js`.**

The `Handled in` column is the door out of that ambiguity: it names the file and line where the
action is dispatched, so a `?` is a place to look rather than a shrug.
