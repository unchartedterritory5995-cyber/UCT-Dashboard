## Findings worth keeping

1. **The "writes nothing" contract holds on real glass.** Read *while the hub was hidden*:
   `hub=ABSENT edgetab=PRESENT pref.enabled=true`. The session hide left the stored
   preference untouched. Measured while hidden on purpose — reading it after an edge-tab
   restore is confounded, since a restore could write `true` back and mask a `false`.
2. **The toast renders real text.** `Hidden for now. Reload to bring it back.` appeared on
   screen. This is the half that shipped broken twice (a `message`/`msg` prop mismatch, and a
   host unmounted by its own action); it is correct on device.
3. **A session hide UNMOUNTS the hub** (`hubFound:false`) — it does not merely set `hidden`.
4. **The edge tab survives a persistent hide.** After the Settings OFF *and a reload*,
   `edgetab=PRESENT`. The way back exists for both kinds of hide, as the recovery design requires.
5. **The edge tab's touch target is 44×44**, i.e. it meets `--tap-min`. The documented
   "12×36px" is the visual pill, not the hit area.
6. **The Settings label reads `Joystick shortcuts (preview)`** verbatim — the string
   `joystickSettingsControls.test.jsx` asserts, and the carrier of the preview framing at stage 2.
7. **The Home actions sheet enumerates NINE actions** — Scan · Chart · Flow · Breadth ·
   Journal · Notebook · Wire · Calendar · Voice — corroborating on-device the registry's
   declared nine that the stage-2 PR body claims, against the registry comment's wrong
   "eight bubbles instead of seven".
8. **Hiding the hub hands the corner to the voice orb**, which then fires its own
   "Meet Compass" first-run popover. Designed behaviour (`App.jsx` gates the orb on hub
   activity), recorded because it reads as a surprise the first time.
9. The admin trace section is present and `traceGestures` is **off** — the `data-hub-trace`
   read path exists on this build.

## Instrument corrections made during the run (each read as a product defect first)

- ⚠️ **`enabled=undefined` was MY BUG, not a missing key.** `/api/auth/preferences` returns
  `joystick_hub` as a **JSON string**, so `j.joystick_hub.enabled` is `undefined` by
  construction. Parsed, it read `enabled=false` exactly as expected. A finding published from
  the unparsed read would have been fiction.
- ⚠️ **A process probe reported 7 concurrent gates and FOREIGN shard workers** — the
  2026-09-12 OOM-sweep signature. It was the probe **matching its own command line**: the bash
  wrappers carrying it contain the literal strings `--shard` and `gate_shards`. Exactly one
  gate was running. Fixed by scoping on process `Name` plus a specific path fragment.
- ⚠️ **`curl` from the Bash tool cannot reach production on this box** — two probes returned
  `http_code=000` on a 25 s timeout, which reads exactly like an outage. Python `urllib` got
  HTTP 200 immediately. **Use Python for prod probes here.**

## Procedure notes for the next operator

- Open the Live session **first**, mint the link **second** — the token lives 2 minutes.
- `tools/smoke_login_link.py` needs `SMOKE_EMAIL`/`SMOKE_PASSWORD`, which are present at
  **User** scope and absent from the process environment. Read them with
  `[Environment]::GetEnvironmentVariable(name,'User')` and set them on the process first.
- Verify the typed URL before pressing go. A mistyped URL on a mirror once ran a Google
  search for a live token; the fragment protects the server log, not a search box.
- The device mirror maps to the operator's screen as
  `screen_x = 476 + 0.914·css_x`, `screen_y = 97 + 0.914·css_y` at a 1600×1180 window with
  DevTools **closed**. Derive it from two known control centres; it held to ~3 px all run.
- Safari Web Inspector attaches **without reloading** the device tab (console history
  survived one cycle and was cleared on the next — the *tab* is what must not reload).
- In-page scrolling fights momentum and re-anchors. `el.scrollIntoView({block:'center'})`
  from the console, then `getBoundingClientRect()`, is deterministic where scrolling is not.
