## ⛔ WHAT THIS RUN DID **NOT** MEASURE — read before quoting it as full coverage

The tool's own PASS criteria are: every top-level route loads, every clickable nav entry moves
**both** the URL and a screen fingerprint, and no route's main thread is starved. Two things in
the owner's broader wording are **not** in that set, and neither was measured here:

1. **Hub mount / `hideOnRoute`.** The hub requires `(max-width:1023px) AND (pointer:coarse)`
   (`useHubActive.js:84`). This run is a desktop viewport with a fine pointer, so **the hub could
   not mount on any route** — "it did not appear where it shouldn't" is true here for a reason
   that proves nothing about the rule. Measuring it needs a touch-emulating context
   (`has_touch`/`is_mobile`), which is a different instrument.
2. **Console errors from hub files.** `hub_nav_smoke.py` does not subscribe to `page.on("console")`,
   so no claim is made either way.

⭐ Recorded rather than quietly folded in: a pass whose scope is overstated is how a green
instrument ends up standing in for one nobody ran.
