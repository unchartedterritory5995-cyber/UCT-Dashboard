**Input:** `docs/superpowers/specs/2026-07-06-liveflow-worker-deploy-survival-design.md` (v1) + reviews: attack:P0-config, attack:P1-patch, attack:P2-gapfill, attack:P3-success-systems, attack:coordination.
**Ground truth re-verified this session against `origin/master` @ `4773872d` (Jul 6, 17:23 CT — fresher than the 054c60cd the reviewers used; all load-bearing facts hold).**

The two headline findings both invert v1 premises and both would have shipped "green" while doing nothing:
1. **The plan's own P1 registration instruction is wrong** — main.py already uses `lifespan=`; the prescribed `@app.on_event("shutdown")` hook would be silently ignored.
2. **The plan's P0 makes deploys WORSE without a companion fix** — the startCommand shell wrapper swallows SIGTERM; `drainingSeconds=30` without `exec` = 30s zombie + still-dirty kill + slower deploys.
