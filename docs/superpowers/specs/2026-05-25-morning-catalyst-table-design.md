# Morning Catalyst Table — Design

**Date:** 2026-05-25
**Status:** Proposed (Phase 1 ships immediately; Phases 2–4 sequenced after)
**Builds on:** `2026-05-25-twitter-news-ingestion-design.md` (the Twitter ingestion pipeline this consumes)
**Goal:** Build a multi-source pre-market intelligence engine that scores every meaningful candidate ticker each day, picks the top 12 with a forced category mix, and uses Claude Opus 4.7 to synthesize a 2–3 sentence catalyst description per entry. Surfaces as a full-width Dashboard tile that replaces (eventually) the role of the existing MoversSidebar.

## Problem

The user wants a single morning view that answers, in seconds, **what's moving today and why** — across earnings, M&A, FDA, contracts, halts, analyst actions, unusual flow, and unexplained gappers. Today:

- `MoversSidebar` shows gappers ≥3% with no context — "why is XYZ ripping?" is unanswered
- `EarningsModal` has Claude-summarized financials but only for tickers the user already opens
- `news_aggregator` pulls RSS but doesn't join headlines to tickers
- The Twitter pipeline (just shipped) surfaces tweets per ticker but doesn't synthesize them into prose
- Nothing pulls these signals together, scores them, picks the best, and writes a coherent "this is the story" sentence

The user's friend has a tool with exactly this view (10-column wide table; SYMBOL / PRICE / GAP / volume metrics / TAGS / NEWS). The user wants the same end-result but leaner (6 columns), more curated (top 12, not top 50), and uses our existing pipelines (Massive + Finnhub + EW + TwitterAPI.io + RSS) plus new sources in later phases.

## Goals (Phase 1)

1. **Replace the role** of MoversSidebar for "what's moving + why" with a wider, synthesized tile at the top of Dashboard
2. **One synthesis per ticker per refresh**, generated by Claude Opus 4.7 from all signals available
3. **Forced category mix** so the list isn't dominated by one bucket on busy days (6 Catalyst, 3 Earnings, 2 Gapper, 1 News by default; redistributable)
4. **Smart cadence** that aligns Opus spend with when data actually changes (5-min pre-market + AMC; 30-min midday; hourly overnight)
5. **Cost guardrails** — $5/day soft cap, $10/day hard cutoff
6. **Skip-if-stable** — don't re-synthesize a ticker if its raw signals haven't changed since last call
7. **Full history persistence** — schema supports historical browsing from day 1 (UI for browsing deferred to Phase 4)

## Non-goals (Phase 1 — explicitly deferred)

- Twitter advanced_search beyond curated accounts → **Phase 2**
- AlphaVantage NEWS_SENTIMENT per ticker → **Phase 2**
- Perplexity finance_search fallback → **Phase 2**
- Watchlist highlight / alerts on catalysts → **Phase 3**
- Tag chip filtering UI → **Phase 3**
- History browser UI (`/catalysts/history`) → **Phase 4**
- Compass 🧭 button on catalyst rows → **Phase 4**
- Dashboard visual reshape / MoversSidebar retirement → **Phase 4**
- Audio digest, sector heatmap, email digest, backtesting tool → unscheduled "added features" pool

## Account / model selections (locked)

- **Synthesis model:** `claude-opus-4-7` (per `feedback_opus_for_synthesis` memory). Haiku is the fallback when Opus fails.
- **Refresh model:** scheduler runs every 5 min in pre-market + AMC bursts, every 30 min midday, every hour as safety net.
- **Coverage:** US equities cap_universe ($300M+, the existing 3,685-ticker set) + futures via yfinance (ES/NQ/CL/GC/BTC).
- **No per-user customization** in Phase 1 — same top 12 for everyone. Per-user pref deferred indefinitely.

### Schema (`/data/catalysts.db`)

```sql
CREATE TABLE catalysts (
  market_date     TEXT NOT NULL,        -- "2026-05-26" (ET; the trading day this row is for)
  ticker          TEXT NOT NULL,
  rank            INTEGER,              -- 1..12 if in top list, NULL if scored but not selected
  score           REAL,                 -- composite score
  tag             TEXT,                 -- 'Catalyst' | 'Earnings' | 'Gapper' | 'News'
  price           REAL,
  gap_pct         REAL,
  vol_x           REAL,
  market_cap      REAL,
  sector          TEXT,
  -- synthesized fields
  thesis_text     TEXT,                 -- Opus output, ~2-3 sentences
  thesis_model    TEXT,                 -- "claude-opus-4-7" (or fallback "claude-haiku-4-5-...")
  thesis_at       INTEGER,              -- unix when synthesized
  thesis_sources  TEXT,                 -- JSON list of source URLs cited by Opus
  signals_hash    TEXT,                 -- SHA1 of raw_signals; used for skip-if-stable
  -- audit / retro
  raw_signals     TEXT,                 -- JSON dump of all source signals at synthesis time
  PRIMARY KEY (market_date, ticker)
);
CREATE INDEX idx_catalysts_date_rank ON catalysts(market_date, rank);
CREATE INDEX idx_catalysts_date_score ON catalysts(market_date, score DESC);

CREATE TABLE catalyst_cost_log (
  ts              INTEGER NOT NULL,     -- unix when call happened
  market_date     TEXT NOT NULL,        -- the trading day this call was for
  ticker          TEXT NOT NULL,
  model           TEXT NOT NULL,        -- 'claude-opus-4-7' or fallback
  input_tokens    INTEGER,
  output_tokens   INTEGER,
  cost_usd        REAL,
  was_cached      INTEGER DEFAULT 0     -- 1 if skip-if-stable triggered (no real call)
);
CREATE INDEX idx_catalyst_cost_date ON catalyst_cost_log(market_date);
```

**Retention:** indefinite. Cap is ~12 rows × 252 trading days × ~2 KB = ~6 MB/year. Will not bloat.

### Composite scoring (Phase 1 weights — tunable via env)

```python
def score(c: Candidate) -> float:
    s = abs(c.gap_pct) * 1.0                                  # raw gap, primary signal
    s += math.log(max(1, c.vol_x)) * 15                       # log-volume bonus (plateaus)
    s += c.tweet_mention_count * 5                            # social signal
    s += c.rss_headline_count * 8                             # newswire signal (heavier)
    if c.earnings_just_reported:
        s += 20                                               # huge bonus for AMC/BMO reporters
    if c.scanner_setup is not None:
        s += 12                                               # UCT scanner already flagged it
    if c.price < 5.0:
        s -= 20                                               # downweight penny territory
    if c.price < 2.0:
        s -= 30                                               # additional penalty below $2
    s += c.sector_momentum_count * 5                          # +5 per peer in candidate pool
    return s
```

All weights expose as env vars (`CATALYST_SCORE_W_GAP`, `CATALYST_SCORE_W_TWEET_MENTION`, etc.) so they're tunable without redeploy.

### Tag assignment (deterministic, runs before scoring)

```python
def assign_tag(c: Candidate) -> str:
    if c.earnings_meta and c.earnings_meta.reported_within_hours(36):
        return 'Earnings'
    if c.tweet_mention_count >= 2 or c.rss_headline_count >= 1:
        return 'Catalyst'
    if abs(c.gap_pct) >= 5.0 and c.vol_x >= 3.0:
        return 'Gapper'
    if c.tweet_mention_count >= 1 or c.rss_headline_count >= 1:
        return 'News'
    return None   # fails to make any tag — falls out of consideration
```

Order matters — Earnings wins, then Catalyst, then Gapper, then News.

### Selection (forced category mix)

```python
def select_top_12(scored: list[Candidate]) -> list[Candidate]:
    buckets = {'Catalyst': [], 'Earnings': [], 'Gapper': [], 'News': []}
    for c in scored:
        if c.tag in buckets:
            buckets[c.tag].append(c)
    for k in buckets:
        buckets[k].sort(key=lambda c: c.score, reverse=True)

    quotas = {'Catalyst': 6, 'Earnings': 3, 'Gapper': 2, 'News': 1}
    selected = []
    for tag, n in quotas.items():
        selected.extend(buckets[tag][:n])

    # If any bucket short, fill from the next-highest-scored anywhere
    if len(selected) < 12:
        remaining = sorted([c for c in scored if c not in selected],
                           key=lambda c: c.score, reverse=True)
        selected.extend(remaining[:12 - len(selected)])

    return sorted(selected, key=lambda c: c.score, reverse=True)
```

## Synthesis pipeline

### Per-ticker Opus 4.7 call

```python
SYSTEM_PROMPT = """You write pre-market trading catalyst summaries for a
professional trader's morning dashboard.

Rules:
  - Output JSON only: {"thesis": "...", "tag": "...", "source_urls": [...]}
  - thesis is 2–3 sentences, plain factual English, NO buy/sell recommendations
  - Bold $AMOUNTS, percentages, and company names with **markdown**
  - Cite source category in parentheses: (Earnings · Tweet · News · Scanner)
  - If signals are thin or contradictory, say so explicitly ("no clear catalyst identified")
  - Never invent facts. Only synthesize what's in the SIGNALS block."""

USER_PROMPT_TEMPLATE = """Synthesize a catalyst for {ticker} ({company}).

SIGNALS:
- Price: ${price}, gap {gap_pct}%, vol {vol_x}x ADV
- Market cap: ${market_cap_fmt}
- Sector: {sector}

Tweets (last 24h, {n_tweets} total):
{tweet_block}

RSS headlines ({n_rss} total):
{rss_block}

Earnings: {earnings_block}

UCT scanner: {scanner_block}

Output the JSON now."""
```

Each candidate's signals are formatted into the prompt by `synthesize.format_prompt(candidate)`. Empty signal sections render as `(none)` so the prompt stays uniform.

**Model:** `claude-opus-4-7`
**Max output tokens:** 400
**Temperature:** 0.3 (factual; mild creativity for sentence variety)
**Per-call cost estimate:** ~$0.015 (Opus 4.7 pricing × ~1K in / ~250 out)

### Skip-if-stable optimization

```python
def synthesize_ticker(c: Candidate) -> Thesis:
    signals_hash = hashlib.sha1(json.dumps(c.raw_signals, sort_keys=True).encode()).hexdigest()
    prior = store.get_today(c.ticker)
    if prior and prior.signals_hash == signals_hash:
        # Nothing changed since last call — reuse prior thesis
        store.log_cost_skip(c.ticker)
        return prior.thesis
    # Real call
    return _call_opus(c)
```

This collapses most calls on quiet days. Empirically, expect 70–90% of refreshes during midday to skip after the first call.

### Failure handling

| Failure | Action |
|---|---|
| Opus 5xx / rate limit | Backoff 30s, retry once, then fall back to Haiku with same prompt; tag `thesis_model='claude-haiku-...'` |
| Opus returns malformed JSON | Log + skip; keep prior thesis if exists; admin stats marks failure count |
| All sources silent for a ticker | Synthesis prompt requires the literal substring `"no clear catalyst"` when `len(thesis_sources) == 0`. Post-call validator in `synthesize.py` checks this and re-prompts once if missing; on second failure, stores `thesis_text = "No clear catalyst identified. Source pool was thin."` directly without an LLM call. |
| Cost cap exceeded ($10/day hard) | Disable synthesis for remainder of day. UI shows last-good thesis with "(synthesis paused — daily cost cap reached)" footer. Auto-resumes next ET day. |

## Risks (named explicitly)

| Risk | Mitigation |
|---|---|
| **Opus hallucinates a wrong catalyst** | Synthesis prompt requires source citation `(Earnings · Tweet · News)`; UI shows `thesis_sources` URLs on hover. If no sources, prompt mandates "no clear catalyst identified" — enforced via post-validation. |
| **Opus generates legally-problematic prose** ("BUY NOW") | System prompt explicitly forbids buy/sell recommendations. Tile footer adds disclaimer "Informational only. Not investment advice." |
| **Cost runaway** | Soft cap $5/day logs warning. Hard cap $10/day disables synthesis for remainder of day. Skip-if-stable hash keeps quiet days near $0. |
| **Source goes down** (Massive 524, Finnhub 500, RSS timeout) | Each source pull wrapped in try/except → returns []. Score function tolerates missing data (lower score). Engine never blocks on one source. |
| **Stale data masquerading as fresh** | `thesis_at` timestamp shown in tile header ("updated 2 min ago"). > 30 min stale during market hours → amber. > 2h → red. |
| **Same catalyst surfaces 2 days in a row** | `last_surfaced_at` per ticker; if catalyst was top-12 yesterday with same source URLs, deprioritize via score penalty (still surfaceable, just lower). |
| **Penny stock pump rises to top** | Price floor $2 (env-configurable) + below-$5 penalty in scoring + cap_universe floor at $300M. |
| **TwitterAPI.io key revoked / billing failure** | Existing `tweet_poll_state.last_poll_status` tracks; catalyst engine treats no-tweets as "no signal" and proceeds with other sources. |
| **News source claims "exclusive" but it's a copycat** | Source priority in scoring: SEC filings > newswire RSS > tweets > UCT scanner. Earliest-timestamp signal wins citation slot. |
| **Compass automation interaction** | Catalyst engine does NOT touch Compass. The 🧭 button (Phase 4) is user-initiated only, respecting `feedback_compass_automation_paused`. |
| **Partner-collab safety** (`project_partner_collab_branch`) | None of the touched files (`Dashboard.jsx`, new files under `api/services/catalyst/`) are partner-edited. Safe. |
| **Wrong scoring weights → bad picks** | All weights are env vars. Tune live without code change. Admin stats page (Phase 2) will surface "would-have-been-picked" candidates so we can audit. |
