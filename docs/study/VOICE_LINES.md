# Study — voice lines for the owner to record

The coach speaks in the owner's recorded voice only. No synthetic voice, ever. Record each line as a short MP3
(one to three seconds, phone is fine), name the file exactly as the key below, and drop the files in
`app/public/study/voice/`. The player shows the caption and stays silent for any line that has no file yet.

| key | line | where it plays |
|---|---|---|
| `welcome` | "Let's find a setup." | lesson intro |
| `right` | "That's it." | right answer |
| `right_combo` | "You're on a run." | third right in a row |
| `wrong` | "Not that one. Look again." | wrong answer |
| `red_day` | "Sellers finished the day in charge." | story, the red day |
| `kicker` | "Opens above the red body, closes strong. Sellers are trapped." | story, the Kicker |
| `line` | "That low is the line." | story, the Kicker; answer card |
| `entry` | "Over the previous day's high, or the opening range break." | answer card |
| `buy_perfect` | "Right on the trigger." | hit BUY on the bar |
| `buy_early` | "Too early. Nothing has triggered." | hit BUY before the trigger |
| `buy_late` | "Late. The move was already on." | hit BUY two or more bars late |
| `lesson_done` | "Lesson done. See you tomorrow." | end of lesson |
| `level_up` | "Level up." | rank change |
| `streak` | "Streak alive." | streak screen |
| `chest` | "Open it." | daily chest |
| `boss_win` | "That's a trader." | boss pass |
| `boss_fail` | "Not yet. Review and come back." | boss fail |
