**Decisions that shape everything (2026-10-17):**
- Inside Courses, name "Study", live for all paid members from day one (no live users yet), kill switch `STUDY_ENABLED`.
- **No runtime AI / API spend.** Items ship with pre-written answer + one-line lesson. New items produced in scheduled Claude Code sessions, reviewed, imported (`POST /api/study/import`). Nightly detector items use rule-filled templates, drafts until reviewed.
- **Patrick reviews every item one by one** (both curricula) and wants to build the full bank (5,000+ Method, 2,500+ Foundations) with both authored in parallel ("all of it"). Corrections stored as training data.
- **Voice rule (strong):** sound like a person/friend/mentor, not "AI slop"; no shorthand like "regime/dial/tape" in questions until taught, then in plain words. `docs/study/VOICE.md`.
- Units = questions only + short exciting intro (AI-produced video, cloned Patrick voice w/ consent, brand motion graphics + stylized animated host; built locally, reviewed, uploaded). 3 levels × 3 rungs per unit, Test-out on every unit, optional placement test. Formats: MCQ/TF/fill-in, tap-the-chart, scenario stories.
- Open map (no locks); random mix weighted to weak skills; badges never removed (Fresh / Needs-a-refresh + bonus XP); streaks every calendar day, 1 free miss/week; 10-item daily set + unlimited practice; always reveal ticker/dates; real interactive chart locked down; sound/haptics, session combos, end card, animated trail path; weekly XP leaderboard with accuracy shown, on by default (opt-out), no Discuss threads; reminders push+bell opt-in.
- Content: 26 setups; regime drills use the firm's recorded tier word, never cutoffs; famous charts kept everywhere; Sunday Scans + archive calls early; Desk AND #tsdr video "listen" drills; catalysts drills Patrick-reviewed; own-journal autopsies opt-in; rule-scored plan builder instead of AI-graded free text; history numbers computed from our own data; fundamentals from frozen real snapshots.
- **House sizing rule (workshop outcome):** risk 0.25%–2%/trade by quality/performance/market/edge, flat-risk also valid; stop = LOD or prior LOD first, structure/ATR supporting; size derived from stop (1% stop at 50% size = 0.5% risk); grid (`houseSizing.json`) is a cap layer, not the lesson; heat ≤10%, 5–10 positions, progressive exposure.
- **Still open:** pass-bar numbers (Patrick reviews), intro-video toolchain + cost (propose, he approves before first render), voice-clone consent record.
