# UNITS-method.md: the UCT Method unit list for Study

Status: Phase 0 draft for owner sign-off (2026-10-17). Keyed on the shipped course's 16 modules and 79 lessons (`docs/curriculum/uct_method_course.json`), per spec 13.3 C1. Lesson keys are `uct-method:<slug of the title>`, as `education_curriculum.py` derives them; the course JSON itself carries no id.

1. Tracks are the one navigation axis (13.7 D1): Regime, Scan, Setup, Size, Manage, Review, Calls, Overlay. The station name survives as each unit's eyebrow.
2. Everything is open. No locks. Rung order is the default path and Test out is the only skip (13.5 P3).
3. Every unit is 3 levels x 3 rungs: Learn 1-3, Practise 1-3, Prove 1-3. Gold at rung 9.
4. Every unit opens with 2-3 unscored walk-throughs (Learn 1), the mentor walking the chart (13.9 decision 1). No reading pages.
5. Every setup unit ships with at least one approved LOSS traded correctly (4.8 failure cases; 13.4 rule 3 for where losses come from).
6. Machine labels follow C14: a detection is a spot key only at confidence 70 or more with a resolved outcome inside a stated window; split and unresolved cases become grade items; expired means undecided; next items use one 20-session window.
7. Tier words follow B2: the firm's recorded band with its tier_scale_id for 2026 dates; pre-2026 dates ask which signposts had fired, never a tier.
8. Numbers follow C19 and C20: a numeric key comes from a sourced criterion or is asked as the firm's number; every MA number is tagged by whose system.

Counts: Regime 10 · Scan 12 · Setup 39 · Size 11 · Manage 7 · Review 11 · Calls 3 · Overlay 3 · total 96 units · about 5,605 questions at launch (target 5,000+).

Column key: supply = good / medium / thin / none (13.4). Drill names are the 4.3 types. A unit with no course lesson shows its nearest lesson as the Read-the-lesson door.
