## ⚠️ One residual, stated rather than fixed

`_dispatch_interaction` still `await`s **`render_v2.handle(interaction, received)`** before any V1
branch is reached. That is a **shared** ack-path await: if V2 were enabled and `handle` ever
blocked, every command's ack would be affected, not just `/buzz`.

⭐ It is not a live hazard today — V2 is dark (`v2_channels() == ()`), and C-02 measured the V2
ack path at **p50 0.0023 ms with every render slot starved and the queue loaded**. But it is the
only await left on the path, it is in scope the moment V2 turns on, and per H14 a hazard class is
named rather than filed as interesting. It belongs to the flip checklist, not to this branch.
