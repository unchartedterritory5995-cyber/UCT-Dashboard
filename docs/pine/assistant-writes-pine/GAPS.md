GENERATED by `python tools/assistant_gaps_build.py` from the engine's own verdict on each gap probe
(`app/src/components/chart/supportLoop/assistantGaps.json`). Do not edit by hand.

Create Indicator's assistant writes Pine for what a formula cannot hold, and the engine judges the script.
So what stands between a request and an indicator is what the ENGINE does with the script. Each row below is
the smallest script that shows one thing a member might ask for, run through the member's own paste path, and
what the engine said. A row leaves this file by itself the day the engine serves its probe.

This file holds capabilities only: no member's request, no answer and no count from any live round.

## Probes the engine serves today

Asked the same way, and not a gap: `hline` (a horizontal level drawn with hline), `plotbar` (bars in the chart's own prices, coloured by a rule (plotbar)), `plotbar-computed` (bars drawn from computed values (plotbar)), `vwap-deviation-bands` (vWAP with its own standard deviation bands), `regression-channel-deviation` (a regression channel whose bands are the deviation around the line), `schaff-trend-cycle` (the Schaff Trend Cycle in its published two-stage form), `rsi-divergence-pivots` (a divergence between price and an oscillator, read pivot to pivot), `regression-channel-residual` (a regression channel whose bands are the deviation of price around the line), `zigzag-lines` (a zigzag that joins swing highs and lows with lines), `zones-extended-right` (zones as boxes that start at a past bar and extend to the right), `linefill` (a shaded area between two drawn lines (linefill)), `input-text-area` (a multi-line text setting (input.text_area)).

### `volume-profile-boxes`

```pine
//@version=5
indicator("probe", overlay=true)
n = input.int(60, "Bars")
rows = input.int(12, "Rows")
var box[] bs = array.new_box(0)
if barstate.islast
    for b in bs
        box.delete(b)
    array.clear(bs)
    hi = ta.highest(high, n)
    lo = ta.lowest(low, n)
    step = (hi - lo) / rows
    for r = 0 to rows - 1
        float vol = 0.0
        for i = 0 to n - 1
            if close[i] >= lo + r * step and close[i] < lo + (r + 1) * step
                vol += volume[i]
        array.push(bs, box.new(bar_index - n, lo + (r + 1) * step, bar_index - n + math.round(vol / ta.highest(volume, n) * 3), lo + r * step, bgcolor=color.new(color.blue, 70)))
```
