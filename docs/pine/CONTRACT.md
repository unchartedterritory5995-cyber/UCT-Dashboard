nothing outlives the run that made it. Only a file that is *committed* and read by
*another lane* can go stale, and that is what this page lists.

## R12 — one field name, and it is `version`

**Measured, not chosen.** The contract carried four spellings: `tableVersion`
(`closedTable.json`), `version` (`conceptVocabulary.json`, `starterScans.json`), and
none (`symbolScope.json`, `lookback_agreement.json`). `version` is the majority and the
generic name; `tableVersion` belongs to `closedTable.json`, which is hand-authored.

⛔ **ADDITIVE. Nothing was removed, and the order is the point.** **No Python reader
reads any version field today** — zero programmatic reads across the 23 rails;
`tableVersion` appears only in prose and comments. So the field is **written before it
is read**, which is the only safe order. Removing any existing spelling waits until a
reader is measured reading `version`, and is its own commit.

⛔ **It is added at the WRITER, never into the artifact.** `lookback_agreement.json` is
regenerated by its test; a hand-edit would vanish on the next run. Proven additive by
key-set rather than by line count — the file is single-line compact JSON by design
(118KB against 466KB pretty), so a line count cannot show it: **one key added, none
removed, every pre-existing value and all 54 rows byte-identical.**

## What a reader must do on an unknown version

> **REFUSE, and say which version it found. Never zero, never a default.**

A reader that treats an unknown version as "no data" reports a green nothing, which is
this repo's most expensive failure shape — `tools/ast_conformance.py` already gets this
right and **refuses rather than reporting zero differences** when a lane cannot be
measured. A version it does not recognise is the same situation: the artifact may be
newer than the reader, and answering `0` would let a real divergence pass as agreement.

## The rail

`app/src/components/chart/engine/ast/contractVersions.test.js`.

It asserts the **value** each JS-written file carries, not that a field exists — *"has
a version"* is the adjacent property, and a file could carry `version: undefined` or a
version no reader knows and still pass a presence check
(`lesson_a_guard_that_tests_the_adjacent_thing`, four instances on record). It also
asserts the field is present **at the writer**, since that is the half a regeneration
can undo; that no fifth spelling has appeared; and that the transient names above are
still not committed — if one becomes committed it joins this table and needs a version.
