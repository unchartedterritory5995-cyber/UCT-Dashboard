# Trading Brain setup templates → Wisdom setup vocabulary (proposal, 2026-11-03)

**Status: PROPOSAL. Needs Wisdom maintainer review before any merge. DO NOT MERGE.** Merges are frozen program-wide.

Owner decision 2026-11-03: *approved with restrictions*. The proposal maps all 48 templates; tells genuinely missing concepts apart from aliases, synonyms and overlapping definitions; keeps every existing canonical id and behaviour; resolves ambiguous names explicitly or leaves them for the owner (no guessing); does not touch the Wisdom scoring engine, setup evaluation logic, historical statistics or the partner's Brain; and holds for the owner anything that would change Wisdom's trading methodology rather than add a vocabulary entry.

## Rules applied (W1 §3, as recorded in the setup-vocabulary-v1.json `_readme`, `core/vocab.py` and the rail tests)
- **W1 §3.1:** an entry with thin evidence stays a `candidate`. The new entries have **no** Wisdom author source located yet, so all 17 are `status: candidate` with `evidence_strength: "none"`, `evidence: []` and `evidence_count: 0`. The 27 approved names are unchanged.
- **W1 §3.2:** the vocabulary is the one authority. Only the `engine_setup_templates` rows that a new entry resolves were changed (17 rows: null → new id, mismatch 0). No other list was re-mapped (see the follow-ups).
- **W1 §3.3:** the recorded mismatches (Flat Base / Rectangle → `range_breakout`, PEG → `earnings_gap_up` "owner to rule") stay exactly as they are, with no renames.
- **W1 §3.6:** new names normally enter as candidates through the owner's review queue. These proposed entries are candidates, and the owner/maintainer decides here.
- **W1 §0.4f (public repository):** `definition: null` and a locator only. Aliases are name-like, at most three words, with no price level. No Brain description text is copied: the "gist" in the table is a short paraphrase.
- **W1 §11.5:** the change is additive only. No entry, id, alias or field of the 32 existing entries changed (byte-identical, same order). `version`, `built_at`, `_readme` and `ambiguous_aliases` are unchanged.

## For the owner: HOLD-methodology (7)
1. **7-Week Short Rule** is a hold-time management rule, not a setup. Adding it would need a new vocabulary kind.
2. **EP**, 3. **BGU**, 4. **Gap-and-Go** and 5. **Power Play** form the gap family. Wisdom files catalyst gaps under `earnings_gap_up` (trader_archive `ep`/`peg_flag`, mismatch 1), and the PEG ruling is still pending. Separate entries would split that taxonomy before the ruling. Gap-and-Go's alias "ER Gapper" already belongs to `earnings_gap_up`.
6. **Measured Move** is Brandt's classical-pattern approach with measured-move targets. It is a targeting method, not one setup.
7. **Short Squeeze** is a positioning/catalyst condition. The maps already rule that catalyst reads are "not a chart setup in the vocabulary's sense".
