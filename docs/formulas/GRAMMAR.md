# The formula grammar

> Generated from `app/src/components/chart/engine/ast/closedTable.json`.
> Do not edit this file by hand — see "How this page stays true" at the end.

Manifest version **2**. Every name below is one this engine
can compute, chart, save and run across the whole universe as a screen.

## Why the list is closed

A formula here has to be decidable **before it runs**: the engine works out how
much history it needs by adding up the tree, without evaluating anything. That is
what lets one saved formula sweep thousands of symbols on a schedule instead of
being redrawn one chart at a time. It is also why a window has to be a plain whole
number, and why a running total has to say where it starts.

If a pasted script names something absent from this page, the door refuses it and
says which name and why — it never guesses a meaning.

## How this page stays true

It is generated from the manifest, and a test regenerates it on every run and
fails if this file differs. So it cannot drift from what the engine actually
declares — the failure mode a hand-written reference has, where a function is
renamed and the page keeps describing the old one.

To update it after changing the manifest:

```
cd app && FORMULA_DOCS_WRITE=1 npx vitest run src/components/chart/engine/ast/formulaDocs.test.js
```
