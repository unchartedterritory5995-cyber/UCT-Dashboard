The order I go through before the open.

- [ ] Read the overnight futures and the index levels that matter.
- [ ] Check which names on the watchlist report or have news.
- [ ] Mark the prior session's high and low on the three best setups.
- [ ] Decide the maximum loss for the session and write it here.
- [ ] Close every tab that is not a chart or this notebook.
