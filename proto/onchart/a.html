Concept A — Click Popover

Track B · prototype ← all concepts

The label is the button. Rest shows a colour rail, a name and a value and nothing else. Hover tints the row and reveals one chevron in a gutter that was always reserved — so nothing moves. Click (or right-click) opens one compact popover of high-frequency verbs. Drag exists but is secondary. Every action names the canonical writer it would call — watch the toast.

What this concept claims

  • One verb-surface, two ways in (click and right-click open the same popover). Nothing to learn twice.
  • The hover affordance is a single 9px chevron in a permanently reserved 14px gutter — zero layout shift, zero icon cluster.
  • Hide is a first-class toggle at the top of the popover. Delete sits below a rule and arms before it fires.
  • A multi-plot instance stays one row and one instance; hovering unfolds its plots as read-only sub-rows.
  • Edit in Chart Data is the escape hatch to the full inspector, carrying this exact instanceId.
